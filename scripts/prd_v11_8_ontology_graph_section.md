#### 10.3.5 本体与图谱

##### 10.3.5.1 功能介绍

| 项目 | 说明 |
| --- | --- |
| 功能目标 | 以可版本化的本体语义连接来源数据，形成可被规则运行和风险证据引用的图谱版本 |
| 当前工程入口 | “本体与图谱”下包含“本体管理”和“图谱管理”；“数据接入”旧路由自动跳转至“图谱管理-数据源”页签 |
| 本体模型 | 当前只维护“类、属性、关系”三类元素；业务对象、业务记录、发生事项均统一建模为本体类 |
| 发生语义 | 中标确认、合同变更、采购立项等发生事项不再使用独立事件元素，而是使用带主标识、发生时间属性及参与对象关系的本体类实例表达 |
| 映射模型 | 公共语义映射统一为“节点实例”和“关系”两类；节点实例可映射到本体类或属性，关系只能映射到本体关系 |
| 图谱模型 | 图谱版本统一统计节点和关系；原事件实例及事件数量迁移并入节点口径，不再单列事件数量 |
| 输入 | 本体类、属性和关系定义；源系统元数据；节点识别键、属性字段、关系键；数据范围 |
| 输出 | 本体版本、公共映射修订版本、数据源同步记录、图谱节点/关系版本及依赖快照 |
| 数据与服务 | 本体、数据源、公共映射、图谱版本和依赖快照使用Node.js + MySQL接口；本体编辑模式和画布位置保存在浏览器本地偏好中 |
| 当前边界 | 活动页面不提供独立事件页签、事件映射页签、事件数量列及图谱质量治理页面；质量问题和实体治理接口不作为本章当前可见功能描述 |

##### 10.3.5.3 功能详细设计

本模块按当前活动页面拆分为本体管理、本体编辑、数据源与公共映射、图谱版本与构建四部分。独立事件元素、事件映射和事件数量属于已下线模型，不再作为页面功能或验收对象。

**（一）本体列表页**

**1. 页面布局**

1. 页面头部展示标题“本体管理”、功能说明、“刷新”和“新建本体”。
2. 查询区包含关键词和状态；当前查询在浏览器已加载的MySQL本体列表上执行。
3. 主体为本体列表，展示版本元素统计、状态和操作。
4. 新建本体、校验/发布/复制版本、删除本体草稿均使用弹窗确认。

**2. 查询条件与列表字段**

查询条件：

| 字段 | 控件 | 默认值 | 规则 |
| --- | --- | --- | --- |
| 关键词 | 输入框 | 空 | 匹配本体名称、编码或监管领域 |
| 状态 | 单选下拉 | 全部 | 全部、草稿、待校验、已发布、已废止；已废止仅兼容存量查询 |

列表字段：

| 字段 | 默认显示 | 展示规则 |
| --- | --- | --- |
| 本体名称/编码 | 是 | 名称为详情入口，编码为稳定版本标识 |
| 范围/领域 | 是 | 监管基础本体或领域扩展本体，并展示监管领域 |
| 版本 | 是 | 展示vX.Y版本号 |
| 类/属性/关系 | 是 | 只统计当前版本三类元素，不展示事件数量 |
| 状态 | 是 | 草稿、待校验、已发布；已废止用于兼容历史数据 |
| 更新时间 | 是 | 展示MySQL记录更新时间 |
| 操作 | 是 | 编辑/查看、校验、发布、复制版本、删除 |

**3. 新建本体字段**

| 字段 | 必填 | 控件 | 规则 |
| --- | --- | --- | --- |
| 本体名称 | 是 | 输入框 | 不得为空 |
| 本体编码 | 是 | 输入框 | 3至64位，仅允许大写字母、数字、下划线和中划线；全局唯一 |
| 适用范围 | 否 | 下拉 | 领域扩展本体、监管基础本体 |
| 监管领域 | 否 | 下拉 | 采购、合同、财务、投资、通用 |
| 本体说明 | 否 | 多行输入 | 说明覆盖的业务对象、业务记录和使用边界 |

**4. 操作交互**

| 操作 | 前置条件 | 交互形式 | 成功反馈 | 失败处理 | 权限/审计 |
| --- | --- | --- | --- | --- | --- |
| 查询 | 已加载本体列表 | 设置关键词或状态后点击查询 | 提示查询完成和结果数量 | 保留筛选条件 | 无高危审计 |
| 重置 | 已修改筛选条件 | 点击重置 | 恢复全部状态和空关键词 | 无 | 无 |
| 新建本体 | 具备本体维护权限 | 填写新建弹窗后“创建并编辑” | 创建v0.1草稿并进入编辑器 | 编码格式、名称和唯一性错误时停留弹窗 | 记录新建本体 |
| 编辑/查看 | 对象可访问 | 点击名称或行操作 | 草稿进入编辑态，已发布进入只读态 | 本体不存在时展示空状态 | 记录敏感访问按项目策略执行 |
| 校验 | 状态为草稿 | 确认后调用校验接口 | 无阻断项时进入待校验 | 有阻断项时保持草稿并返回阻断数量 | 记录校验本体版本 |
| 发布 | 状态为待校验 | 展示发布检查清单后确认 | 状态变为已发布 | 未校验、无本体类或存在阻断项时拒绝 | 高危操作审计 |
| 复制版本 | 状态为已发布 | 确认复制 | 创建下一主版本草稿并进入编辑 | 源版本不存在时提示失败 | 记录来源版本与新版本 |
| 删除 | 非已发布且无规则/图谱引用 | 高危确认弹窗 | 从MySQL删除草稿 | 已发布或仍被规则、图谱引用时拒绝 | 高危操作审计 |
| 刷新 | 页面可访问 | 点击刷新 | 当前工程仅展示“本体列表已刷新”提示 | 当前实现未重新调用列表接口 | 试点前改为真实重新加载 |

**5. 页面状态与异常**

| 状态/异常 | 页面表现 | 可用操作 | 恢复方式 |
| --- | --- | --- | --- |
| 无匹配本体 | 展示“没有符合条件的本体” | 重置、新建本体 | 调整筛选 |
| 草稿 | 可编辑并显示校验、删除 | 编辑、校验、删除 | 完成元素配置 |
| 待校验 | 可查看发布清单 | 编辑、发布、删除 | 发布或继续修改后重校验 |
| 已发布 | 全部元素只读 | 查看、复制版本 | 复制新草稿 |
| MySQL加载失败 | App启动提示加载失败，本体列表为空或保留已有状态 | 重试加载 | 恢复数据库连接 |

**（二）本体版本编辑页**

**1. 页面布局**

1. 页面头部展示返回本体列表、本体编码、名称、状态、版本、适用范围和最近保存时间。
2. 页面提供“结构化配置、可视化建模”编辑方式切换；当前本体的最近使用模式保存在浏览器本地，切换时分别保留滚动位置。
3. 草稿或待校验版本提供“保存草稿、校验、发布”；已发布版本仅提供“复制新版本”。
4. 结构化配置页签为“基本信息、类定义、属性、关系、版本记录”，不再包含事件页签。
5. 可视化建模画布只提供“新增类、新增属性、新增关系”，点击类节点可查看该类的属性和关联关系。

**2. 基本信息字段**

| 字段 | 必填 | 控件 | 规则 |
| --- | --- | --- | --- |
| 本体名称 | 是 | 输入框 | 不得为空；已发布只读 |
| 本体编码 | 是 | 只读输入 | 创建后不可修改 |
| 适用范围 | 是 | 下拉 | 监管基础本体、领域扩展本体 |
| 监管领域 | 是 | 下拉 | 通用、采购、合同、财务、投资 |
| 本体说明 | 否 | 多行输入 | 描述覆盖范围和使用边界 |
| 版本统计 | 系统生成 | 摘要面板 | 仅展示类、属性、关系数量 |

**3. 本体元素字段**

类定义：

| 字段 | 必填 | 控件 | 规则 |
| --- | --- | --- | --- |
| 元素类型 | 是 | 只读 | 固定为“类” |
| 元素编码 | 是 | 输入框 | 当前本体内同类型唯一；被属性或关系引用后不可直接修改编码 |
| 中文名称 | 是 | 输入框 | 业务可理解名称 |
| 类型 | 系统生成 | 只读 | 固定为“本体类” |
| 约束 | 否 | 输入框 | 可描述主标识、发生时间必填等 |
| 业务说明 | 否 | 多行输入 | 描述对象、业务记录或概念的语义 |

属性：

| 字段 | 必填 | 控件 | 规则 |
| --- | --- | --- | --- |
| 属性编码/名称 | 是 | 输入框 | 当前本体属性内唯一 |
| 所属类 | 是 | 类选择 | 必须选择当前版本存在的本体类 |
| 数据类型 | 是 | 输入框 | 文本、数字、金额、日期时间等 |
| 约束 | 否 | 输入框 | 主标识、必填、发生时间、敏感等级等 |
| 业务说明 | 否 | 多行输入 | 说明字段业务含义和来源口径 |

关系：

| 字段 | 必填 | 控件 | 规则 |
| --- | --- | --- | --- |
| 关系编码/名称 | 是 | 输入框 | 当前本体关系内唯一 |
| 起点类 | 是 | 类选择 | 必须属于当前版本 |
| 终点类 | 是 | 类选择 | 必须属于当前版本 |
| 关系方向 | 系统生成 | 只读 | 根据起点类和终点类自动形成“起点类 → 终点类” |
| 约束 | 否 | 输入框 | 一对一、一对多、多对多、参与对象等 |
| 业务说明 | 否 | 多行输入 | 描述关系含义、有效范围和时间语义 |

**4. 发生事项建模规则**

| 业务语义 | 当前建模方式 | 示例 |
| --- | --- | --- |
| 发生事项类型 | 建模为普通本体类 | 中标确认、合同变更、采购立项 |
| 节点主标识 | 在该类下新增主标识属性 | 中标确认记录编号 |
| 发生时间 | 在该类下新增日期时间属性并标记“发生时间” | 中标确认发生时间 |
| 参与对象 | 使用本体关系连接业务记录类与业务对象类 | 中标确认 → 采购项目 |
| 图谱落地 | 通过“节点实例”映射生成节点，通过“关系”映射连接参与对象 | 来源记录生成中标确认节点并关联采购项目节点 |

**5. 校验与发布规则**

1. 本体至少包含一个类。
2. 所有元素编码和名称不能为空，同类型编码不得重复。
3. 属性必须引用当前版本存在的所属类。
4. 关系必须同时配置有效的起点类和终点类。
5. 修改或删除被属性、关系引用的类时，系统返回引用冲突并要求先调整依赖。
6. 未配置“主标识”属性时产生提示项，不直接阻断校验。
7. 校验无阻断项后状态进入待校验；只有待校验版本可以发布。
8. 发布后本体和元素只读，修改必须复制新版本。

**6. 操作交互**

| 操作 | 前置条件 | 交互形式 | 成功反馈 | 失败处理 | 权限/审计 |
| --- | --- | --- | --- | --- | --- |
| 切换编辑方式 | 本体已加载 | 点击结构化配置或可视化建模 | 切换视图并记忆模式 | 本地存储不可用时不影响编辑 | 无独立审计 |
| 保存草稿 | 非已发布版本 | 点击保存草稿 | 写入MySQL并更新保存时间 | 名称为空或状态冲突时保留内容 | 记录保存草稿 |
| 新增元素 | 非已发布版本 | 列表按钮或画布工具打开抽屉 | 写入MySQL并更新统计 | 编码重复、字段缺失或引用无效时拒绝 | 记录新增元素 |
| 编辑元素 | 非已发布版本 | 点击列表/画布元素后编辑 | 更新MySQL元素定义 | 类型不可修改；类被引用时禁止修改编码 | 记录编辑元素 |
| 删除元素 | 非已发布版本 | 高危确认弹窗 | 从当前草稿删除并更新统计 | 类仍被属性或关系引用时拒绝 | 记录删除元素 |
| 校验 | 非已发布版本 | 点击校验 | 无阻断项进入待校验 | 返回阻断数量和具体原因 | 记录校验 |
| 发布 | 状态为待校验 | 发布检查弹窗 | 版本变为已发布 | 检查项未通过时拒绝 | 高危审计 |
| 复制新版本 | 已发布版本 | 点击复制新版本 | 创建新草稿并进入新路由 | 复制失败时停留原版本 | 记录版本继承 |

**（三）数据源与公共语义映射**

**1. 页面入口与布局**

| 映射类型 | 来源侧 | 允许的目标类型 | 用途 |
| --- | --- | --- | --- |
| 节点实例 | 节点识别键、普通属性字段、业务记录编号和发生时间 | 本体类或属性 | 识别/创建图谱节点，并写入节点属性；发生事项也通过此类型生成节点 |
| 关系 | 关联键、外键或组合关系键 | 本体关系 | 连接两个已识别节点 |

映射校验规则：

1. 公共映射以“数据源 + 已发布本体”作为唯一维护范围。
2. 修改目标本体元素后，当前映射行和映射集合状态变为待校验，映射修订号加1。
3. 节点实例映射目标必须为当前本体的类或属性。
4. 关系映射目标必须为当前本体的关系。
5. 旧“属性、事件、事件实例”映射数据在数据库初始化时统一迁移为“节点实例”。
6. 存在无效目标、类型不匹配或未知映射类型时，公共映射不能校验通过。
7. 校验通过后，映射行和映射集合状态变为有效，并记录最近校验时间。

**5. 状态与删除约束**

| 操作/状态 | 约束 |
| --- | --- |
| 启用数据源 | 至少存在一条有效语义映射；图谱构建还会按选定本体检查整个公共映射集合是否全部有效 |
| 立即同步 | 数据源必须为启用状态 |
| 删除数据源 | 必须先停用；不得被任何图谱版本引用；不得存在同步记录 |

| 详情本体范围 | 当前数据源详情默认维护ONT-PROC公共映射；其他本体映射主要在图谱构建向导中按选定本体维护 |

公共映射依赖状态：

| 状态 | 含义 | 处理方式 |
| --- | --- | --- |
| ready | 数据源启用、映射存在、目标有效且集合已校验 | 允许继续 |

| invalid | 目标本体元素不存在或映射类型不匹配 | 修正目标后重新校验 |

**4. 构建、发布与删除规则**

1. 新建图谱必须选择一个已发布本体和至少一个启用数据源。
2. 每个所选数据源与本体的公共映射必须全部处于ready。
3. 构建时为每个数据源保存公共映射修订号、状态、条数和完整JSON快照。
4. 新建成功后图谱状态为待发布；编辑校验中、待发布或失败版本时，重新保存来源、映射快照并回到待发布。
5. 图谱版本统一生成节点数量和关系数量，event_count固定归零；存量事件数量迁移并入节点数量。
6. 只有待发布、阻断数为0、依赖本体仍已发布、数据源仍启用且映射快照完整的图谱可以发布。
7. 发布成功后，同一图谱编码下原已发布版本自动转为已归档。
8. 校验中、待发布、失败版本可删除，但被规则版本引用时禁止删除；已发布和已归档版本不可删除。
9. 当前删除确认弹窗文案仍写“仅待发布或失败”，与服务端允许“校验中、待发布、失败”的规则不一致，界面文案应同步修正。
10. 当前构建服务按数据源数量生成演示节点/关系规模，不等同于真实同步后的质量统计；试点前应由构建任务返回真实数量。

**模块业务规则与验收**

| 编号 | 类型 | 规则 |
| --- | --- | --- |
| OG-R1 | 模型约束 | 本体元素只允许类、属性、关系，不再创建独立事件元素 |
| OG-R2 | 建模规则 | 业务对象、业务记录和发生事项统一建模为本体类；发生语义由主标识属性、发生时间属性和参与对象关系表达 |
| OG-R3 | 版本约束 | 已发布本体不可原地修改，必须复制新草稿版本 |
| OG-R4 | 引用约束 | 属性必须引用所属类，关系必须引用有效起点类和终点类；被引用类不可直接改码或删除 |
| OG-R5 | 映射约束 | 公共语义映射只允许节点实例和关系两类；节点实例目标为类/属性，关系目标为关系 |
| OG-R6 | 映射版本 | 公共映射按“数据源 + 本体”管理修订；修改后必须重新校验 |
| OG-R7 | 构建约束 | 图谱仅可选择已发布本体、启用数据源和ready公共映射 |
| OG-R8 | 快照约束 | 图谱构建必须固化本体版本、数据源集合和每个公共映射修订快照 |
| OG-R9 | 图谱口径 | 图谱版本只展示节点和关系数量，存量事件数量迁移并入节点数量 |
| OG-R10 | 发布约束 | 同一图谱编码只保留一个已发布版本，新版本发布后原版本归档 |
| OG-R11 | 数据源删除 | 数据源删除前必须停用，且不得存在图谱引用和同步记录 |
| OG-R12 | 图谱删除 | 仅校验中、待发布、失败且无规则引用的图谱任务可删除 |

验收要求：

1. 本体列表和编辑器不再出现独立事件数量、事件页签或新增事件入口。
2. 可将“中标确认”创建为本体类，并为其配置记录编号、发生时间属性和关联采购项目关系。
3. 旧属性/事件/事件实例映射初始化后统一显示为节点实例，不产生重复映射。
4. 节点实例映射选择关系目标、关系映射选择类/属性目标时必须被服务端拒绝。
5. 图谱列表只展示节点和关系，构建后的event_count为0。
6. 图谱构建时任一数据源停用、映射缺失、待校验或无效，均不能进入确认构建。
7. 图谱发布后同图谱编码原已发布版本自动归档，规则仍可追溯其引用版本。
8. 删除数据源时能分别提示“请先停用、已被图谱引用、已有同步记录”；删除图谱时能提示状态或规则引用阻断。
