#### 10.3.4 场景与规则

##### 10.3.4.1 功能介绍

| 项目 | 说明 |
| --- | --- |
| 功能目标 | 以风险场景版本为统一发布单元，编排确定性标准规则和智能Skill两类检测能力，形成可校验、可试跑、可追溯的风险识别配置 |
| 当前工程入口 | 一级菜单“场景与规则”下包含“风险场景、规则管理、Skill管理”三个二级菜单；活动路由分别为`/scenes`、`/rules`、`/skills` |
| 场景模型 | 场景负责风险主题、监管领域、默认风险等级、适用组织、例外范围和核查模板，不再在场景基本信息中直接配置本体、图谱、主对象或目标类 |
| 检测能力模型 | 标准规则负责基于图谱和本体元素的确定性判断；智能Skill根据审查需求生成审查内容、审查要求和输出结果，并在运行时自动获取场景业务上下文和关联附件 |
| 资产关系 | 规则和Skill均为独立资产，通过版本引用与一个或多个场景版本建立多对多关系；移出场景只解除引用，不删除资产 |
| 版本策略 | 场景状态为草稿、待试跑、待发布、已发布、已停用；已发布或已停用场景只读。规则和Skill没有独立发布入口，随场景发布被锁定为已发布版本 |
| 输入 | 场景基础信息、适用组织、例外范围、核查模板；规则检测范围、判断条件、制度依据和证据要求；Skill名称、领域、风险等级和审查需求 |
| 输出 | 不可变场景版本、关联规则与Skill版本快照、场景试跑任务、规则运行记录、Skill运行记录、预警编号、实际证据和操作审计 |
| 当前边界 | 当前活动页面不提供规则或Skill独立发布、复制新版本和单独试跑入口；规则目录导入接口不作为本章当前可见页面功能 |

##### 10.3.4.3 功能详细设计

本模块按当前活动页面拆分为风险场景管理、场景检测能力编排、规则资产、规则配置、Skill资产和统一发布闭环。场景不再直接承载规则检测范围；规则和Skill也不独立发布，三类对象通过“独立资产 + 场景版本引用 + 场景统一发布”形成闭环。

**（一）风险场景列表页**

**1. 页面布局**

1. 页面头部展示标题“风险场景”、说明、“刷新”和“新建场景”。
2. 筛选区只包含关键词、监管领域和状态，不提供主对象、目标类、本体、图谱和更新时间筛选。
3. 主体为场景当前版本列表，展示规则和Skill两类检测能力数量以及合并后的运行记录数量。
4. 新建场景、停用场景和删除场景使用弹窗；运行记录与操作审计使用右侧抽屉。
5. 列表按当前版本更新时间倒序加载，不在当前页面提供分页和批量操作。

**2. 查询条件**

| 字段 | 控件 | 默认值 | 规则 |
| --- | --- | --- | --- |
| 关键词 | 输入框 | 空 | 模糊匹配场景名称或编码 |
| 监管领域 | 单选下拉 | 全部 | 当前选项为采购、合同、财务、投资 |
| 状态 | 单选下拉 | 全部 | 草稿、待试跑、待发布、已发布、已停用 |

**3. 列表字段**

| 字段 | 展示规则 |
| --- | --- |
| 场景名称/编码 | 名称和编码均来自当前版本；点击进入场景编辑器 |
| 监管领域 | 展示当前版本领域 |
| 默认等级 | 使用重大、高、中、低风险标签 |
| 检测能力 | 分别展示启用规则数量和启用Skill数量 |
| 版本 | 展示当前版本号；点击进入版本记录页签 |
| 状态 | 展示草稿、待试跑、待发布、已发布、已停用 |
| 运行记录 | 合并统计规则运行记录和Skill运行记录；点击打开引用与审计抽屉 |
| 更新时间 | 展示更新人和更新时间 |
| 操作 | 编辑/查看、复制版本、停用、发布入口、删除；按状态动态显示 |

**4. 新建场景字段**

| 字段 | 必填 | 控件 | 规则 |
| --- | --- | --- | --- |
| 场景名称 | 是 | 输入框 | 不得为空 |
| 场景编码 | 是 | 输入框 | 3至64位，仅允许大写字母、数字、下划线和中划线，全局唯一 |
| 监管领域 | 是 | 下拉 | 采购、合同、财务、投资 |
| 默认风险等级 | 是 | 下拉 | 重大、高、中、低 |
| 场景说明 | 创建弹窗可空，发布前必填 | 多行输入 | 描述风险主题、适用边界和不适用情形 |

**5. 操作交互**

| 操作 | 前置条件 | 成功结果 | 失败处理 |
| --- | --- | --- | --- |
| 查询/重置 | 页面已加载 | 按三个条件重新加载列表或恢复全部 | 加载失败保留条件并展示重试 |
| 新建场景 | 名称、编码格式合法 | 创建v0.1草稿并进入编辑器；默认适用组织为中国电子云集团，处理时限为48小时 | 编码重复或格式错误时停留弹窗 |
| 查看/编辑 | 场景可访问 | 草稿、待试跑、待发布进入编辑态；已发布、已停用进入只读态 | 场景不存在时返回列表 |
| 复制版本 | 当前状态为已发布或已停用 | 生成下一主版本草稿，并继承规则与Skill引用 | 已存在草稿、待试跑或待发布版本时拒绝 |
| 停用 | 当前状态为已发布且填写原因 | 状态变为已停用；历史预警和运行记录继续引用原版本 | 原因为空或状态不符时拒绝 |
| 删除 | 当前状态可编辑、场景仅有一个版本且没有任何规则/Skill运行记录 | 删除风险场景及其新建草稿 | 已形成历史版本或已有运行记录时拒绝 |
| 查看运行记录 | 场景存在 | 抽屉展示最近20条规则/Skill运行记录和最近30条操作审计 | 加载失败保留抽屉并提示原因 |

**（二）风险场景编辑器与检测能力编排**

**1. 页面结构**

1. 顶部展示返回场景列表、场景编码、名称、状态、版本、领域和保存状态。
2. 顶部及底部操作区均根据状态显示保存草稿、校验、发起试跑、发布版本或复制新版本。
3. 状态步骤条为“草稿、待试跑、待发布、已发布”；已停用版本在步骤条上按已发布阶段展示并保持只读。
4. 主体页签为“基本信息、风险规则、智能Skill、适用范围、核查模板、版本记录”。
5. 校验结果和试跑结果使用抽屉；选择规则、选择Skill、发起试跑和发布版本使用弹窗。

**2. 基本信息、范围和模板字段**

| 页签 | 字段 | 必填 | 规则 |
| --- | --- | --- | --- |
| 基本信息 | 场景名称 | 是 | 草稿可编辑，已发布/已停用只读 |
| 基本信息 | 场景编码 | 是 | 创建后只读 |
| 基本信息 | 监管领域 | 是 | 采购、合同、财务、投资 |
| 基本信息 | 默认风险等级 | 是 | 被选择“继承场景”的规则作为命中等级 |
| 基本信息 | 场景说明 | 是 | 为空时场景校验阻断 |
| 适用范围 | 适用组织 | 是 | 至少选择一个；当前页面提供中国电子云集团、集团采购中心、财务共享中心、各事业部采购组织和试点事业部 |
| 适用范围 | 例外说明 | 否 | 描述场景级白名单或特殊授权 |
| 适用范围 | 例外有效期 | 否 | 日期控件 |
| 核查模板 | 默认核查要求 | 是 | 为空时校验阻断 |
| 核查模板 | 处理时限 | 是 | 小时，必须大于0 |
| 核查模板 | 必交材料 | 否 | 使用顿号、逗号或中文逗号拆分为材料数组 |

**3. 风险规则页签**

1. 页签头部展示“启用规则数/规则总数”，并提供“选择已有规则”和“新建规则”。
2. 列表字段为规则名称/编码/版本、主对象及本体/图谱、判断类型、命中等级、制度依据与证据要求数量、启停状态和操作。
3. “选择已有规则”加载当前场景尚未引用的独立规则资产，支持多选后一次建立版本引用，不复制规则内容。
4. “新建规则”跳转规则管理并携带`sceneId`；创建完成后自动建立当前场景引用。
5. 可编辑场景提供“编辑”和“移出场景”；已发布或已停用场景只提供“查看”。
6. 移出场景仅删除当前场景版本与规则版本的绑定关系，规则资产继续保留在规则管理中。

**4. 智能Skill页签**

1. 页签头部展示“启用Skill数/Skill总数”，并提供“选择已有Skill”和“新建Skill”。
2. 列表字段为Skill名称/编码/版本、能力类型和领域、审查需求、风险等级、输出结果、启停状态和操作。
3. “选择已有Skill”加载当前场景尚未引用的Skill资产，支持多选后建立版本引用。
4. “新建Skill”进入两步式生成页面并携带`sceneId`；完成创建后自动关联当前场景。
5. 移出场景只解除Skill引用，不删除Skill资产。

**5. 保存与状态回退策略**

1. 场景名称、领域、说明、等级、组织、例外或核查模板发生保存时，场景状态统一回到草稿。
2. 选择、新建、移出规则或Skill时，场景状态统一回到草稿。
3. 被当前可编辑场景引用的共享规则或Skill发生修改时，所有引用该资产的草稿、待试跑和待发布场景均回到草稿。
4. 状态回退同时清空场景校验结果、最近试跑任务和发布依赖哈希，必须重新校验和试跑。
5. 保存使用锁版本号控制并发；锁版本不一致时保留本地内容并提示刷新。

**6. 场景校验**

场景校验依次检查：

1. 场景说明不为空。
2. 至少选择一个适用组织。
3. 核查要求不为空且处理时限大于0。
4. 至少存在一条启用规则或一个启用Skill，不要求两类能力必须同时存在。
5. 每条启用规则通过基本字段、检测范围、判断配置、制度依据、证据要求和例外提示检查。
6. 每个启用Skill具备名称、领域、审查需求、审查内容、审查要求和输出结果。
7. 规则引用的本体和图谱已发布，主对象和目标类存在；高级表达式引用的本体元素有效。
8. 无阻断项时状态进入待试跑；有阻断项时保持草稿。校验抽屉支持点击问题定位到风险规则、智能Skill、适用范围或核查模板页签。

**7. 统一场景试跑**

| 参数 | 控件/范围 | 当前页面默认值 |
| --- | --- | --- |
| 样本时间范围 | 下拉；近30天、近90天、近180天 | 近90天 |
| 最大样本数 | 数字；服务端限制10至5000 | 500 |
| 超时时间 | 数字；服务端限制5至300秒 | 60秒 |
| 组织范围 | 全部适用组织或场景已选组织 | 全部适用组织 |

1. 仅待试跑或待发布场景可以创建试跑任务。
2. 默认试跑当前场景全部启用规则和全部启用Skill；没有可执行检测能力时拒绝。
3. 规则按结构化确定性条件执行；Skill按生成的审查要求自动获取场景上下文和附件执行。
4. 结果汇总展示样本总数、命中、未命中、错误、证据完整率和执行耗时。
5. 样本明细标记来源为标准规则或智能Skill，并展示来源名称、风险评分、证据状态、关系跳数或执行说明。
6. 试跑完成后状态进入待发布，并保存包含场景、启用规则和启用Skill完整配置的依赖哈希。

**8. 发布与停用**

1. 发布前状态必须为待发布，最近一次试跑必须已完成且通过。
2. 用户必须填写版本说明和发布原因。
3. 发布时重新计算场景、规则和Skill依赖快照；与试跑后的哈希不一致时拒绝发布并要求重新校验、试跑。
4. 发布成功后场景状态变为已发布，全部关联规则版本和Skill版本同步变为已发布并锁定。
5. 系统根据命中试跑样本写入规则运行记录或Skill运行记录，生成预警编号并固化实际证据快照。
6. 已发布版本只能查看、停用或复制新场景版本；停用不删除历史运行记录。

**（三）规则资产列表**

**1. 页面结构与查询**

1. 页面头部展示“刷新、新增规则”。
2. 筛选区仅提供关键词，匹配规则名称、规则编码或监管领域。
3. 列表展示规则名称/编码/版本、检测范围、判断类型、命中等级、制度依据与证据要求、场景引用、状态、更新时间和操作。
4. 新增规则使用弹窗；删除使用浏览器确认。

**2. 列表状态**

| 状态 | 计算规则 | 可用操作 |
| --- | --- | --- |
| 未完成 | 草稿且当前判断配置不完整 | 编辑；无引用时可删除 |
| 已配置 | 草稿且判断配置已完成 | 编辑；无引用时可删除 |
| 已发布 | 随已发布场景被锁定 | 只读查看 |
| 已停用 | 历史停用资产 | 只读查看 |

**3. 新增规则字段**

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 规则名称 | 是 | 不得为空 |
| 规则编码 | 否 | 留空自动生成；填写时仅允许大写字母、数字、下划线和中划线，全局唯一 |
| 规则类型 | 是 | 属性、字段比对、关系路径、时序、聚合、高级表达式 |
| 命中风险等级 | 是 | 继承场景默认等级或固定为重大、高、中、低 |
| 监管领域 | 是 | 采购、合同、财务、投资、通用 |
| 图谱版本 | 是 | 只能选择已发布图谱 |
| 适用本体 | 系统带出 | 由图谱版本自动确定，不允许独立选择不匹配本体 |
| 主对象 | 是 | 来自图谱对应已发布本体的类 |
| 目标类 | 时序规则可选 | 时序规则新建时显示；编辑器中由计算基准决定是否必填 |

**4. 资产引用和删除规则**

1. 直接从规则管理新建时生成独立规则草稿；从场景进入时创建后自动关联当前场景。
2. 同一规则版本可被多个场景版本引用，列表展示引用数量和场景名称。
3. 被任一场景版本引用的规则不可删除，必须先从所有场景版本解除关联。
4. 已发布或已停用规则不可删除。
5. 当前工程没有规则独立复制新版本按钮；已发布规则如需变更，应新建规则资产，并在新场景草稿中替换引用。

**（四）规则编辑器**

**1. 页面结构**

1. 页面顶部展示返回风险场景或返回规则管理、规则编码/版本、名称、状态、类型、场景引用数和保存状态。
2. 顶部步骤导航为“基本信息、检测口径、依据与证据”；步骤未完成时不能进入下一步。
3. 校验问题以横幅展示，点击问题直接定位对应步骤或依据/证据子页签。
4. 底部固定操作栏提供取消、上一步、保存草稿、下一步和完成规则配置。
5. 已发布、已停用或已被已发布场景引用的规则版本只读。

**2. 基本信息**

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| 规则名称 | 是 | 可编辑草稿允许修改 |
| 规则编码 | 是 | 创建后只读 |
| 监管领域 | 是 | 采购、合同、财务、投资、通用 |
| 命中风险等级 | 是 | 继承场景默认等级或固定覆盖 |
| 规则版本 | 系统生成 | 当前为v0.1，页面只读 |

**3. 检测范围**

1. 图谱版本必须为已发布版本；适用本体由图谱带出。
2. 主对象必须选择本体类。
3. 属性、字段比对、关系路径和高级表达式按规则运行时当前有效数据判断，不展示观察窗口。
4. 时序和聚合规则启用时间范围，可选择“目标类节点的发生时间”或“规则运行时间”作为计算基准。
5. 以目标类节点为基准时必须选择目标类，并配置之前/之后、数值和小时/天/月观察窗口。
6. 切换图谱版本或规则类型时清空原有不兼容条件、路径、时序条件和聚合指标，避免保留失效语义编码。

**4. 六类判断方式**

| 类型 | 配置方式 | 数量和校验限制 |
| --- | --- | --- |
| 属性 | 属性、运算符和固定值，多条件使用AND或OR | 最多10条；为空/不为空不需要比较值 |
| 字段比对 | 判断属性、运算符和对比属性，多条件使用AND或OR | 最多10条 |
| 关系路径 | 从主对象选择一至两跳本体关系，可增加路径属性约束 | 路径1至2跳；约束最多10条 |
| 时序 | 选择一个或多个类节点，设置必须发生或不得发生，共用同一观察窗口 | 至少1条、最多10条 |
| 聚合 | 配置COUNT、SUM、AVG、MAX或MIN，选择统计属性、运算符和阈值 | 至少1项、最多3项，可使用AND或OR |
| 高级表达式 | 使用受控DSL引用本体属性、类、关系和白名单函数 | 最长2000字符；必须含比较或路径判断；禁止SQL、脚本关键字和未知函数 |

高级表达式当前支持的函数为SUM、AVG、MAX、MIN、COUNT、COUNT_DISTINCT、EVENT_COUNT、EXISTS_PATH、DATE_DIFF和ABS。保存与场景校验时均检查括号、引号、首尾逻辑符、字符集、函数白名单和本体元素引用。

**5. 依据与证据**

1. 制度依据和证据要求使用两个子页签。
2. 制度依据字段为制度名称、制度版本、制度条款和条款原文；至少一条记录必须同时具备名称和条款。
3. 证据要求字段为证据名称、数据来源、来源字段、附件要求、完整性要求和说明；至少一项且名称、来源和完整性要求均不能为空。
4. 命中输出由系统按规则类型自动生成，不提供人工多选：基础输出为主体名称与编码、命中条件及实际值、来源记录与版本、规则执行时间；关系路径、时序、聚合和高级表达式分别增加对应明细。
5. 规则级例外为可选多行说明；未配置例外时只生成警告，不阻断完成。

**6. 保存、完成与共享规则影响**

1. 保存草稿使用锁版本号；冲突时提示刷新后重试。
2. 点击“完成规则配置”时先保存，再执行规则结构、语义依赖、高级表达式、制度依据和证据要求校验。
3. 校验通过后从场景进入则返回场景风险规则页签；从规则管理进入则返回规则列表。
4. 当前规则没有独立试跑按钮，必须回到场景完成统一校验和试跑。
5. 修改共享规则时，所有引用该版本且仍可编辑的场景退回草稿并清空校验和试跑结果。
6. 规则已被已发布或已停用场景引用时，服务端拒绝直接修改。

**（五）Skill资产列表与生成编辑器**

**1. Skill资产列表**

1. 页面头部展示“刷新、新增Skill”；关键词匹配Skill名称、编码、领域或能力类型。
2. 列表字段为Skill名称/编码/版本、能力范围、风险等级、审查需求、输出结果、场景引用、状态、更新时间和操作。
3. Skill可被多个场景版本引用；列表展示引用数量和场景名称。
4. 仅草稿且引用数量为0的Skill可删除；已发布、已停用或被场景引用时删除按钮禁用并提示原因。

**2. 两步式Skill生成器**

第一步“基本信息”：

| 字段 | 必填 | 规则 |
| --- | --- | --- |
| Skill名称 | 是 | 不得为空 |
| Skill编码 | 否 | 新建时可填写或留空自动生成；创建后只读 |
| 风险等级 | 是 | 重大、高、中、低 |
| 监管领域 | 是 | 采购、财务、工程、投资、合同、通用 |
| 能力类型 | 系统生成 | 根据审查需求自动判断，如文档异常相似检测、数据与附件一致性检查、风险条款识别等 |

第二步“需求与生成”：

1. 用户填写审查需求，说明需要审查的问题和业务目标。
2. 点击“生成Skill”后，系统生成可编辑的审查内容、审查要求和输出结果。
3. 审查内容描述实际审查的业务对象、事件、图谱关系或附件；审查要求必须要求引用实际数据或原文位置，数据不足时返回无法判断；输出结果包含是否命中、风险评分、判断结论和实际证据。
4. 系统固定生成场景业务上下文、关联附件两类自动输入，以及是否命中、风险评分、判断结论、实际证据四类输出。
5. 系统固定失败策略为“数据不足时返回无法判断，不产生预警并记录运行原因”，当前生成阈值为80。
6. 用户可修改生成结果；再次生成前需确认，重新生成会覆盖审查内容、审查要求和输出结果。
7. 修改审查需求或监管领域后，原生成结果标记为过期，必须重新生成后才能完成创建或修改。

**3. 创建、修改和引用策略**

1. 新建Skill不会在第一步提前生成草稿记录，只有完成生成并点击“完成创建”后才写入Skill资产。
2. 从场景进入时，创建完成后自动关联当前场景；从Skill管理进入时生成独立Skill资产。
3. 修改Skill后执行完整性校验；引用该Skill的可编辑场景全部退回草稿并清空历史校验、试跑和依赖快照。
4. 已发布、已停用或已被已发布场景引用的Skill不可直接修改。
5. 当前工程没有Skill独立复制新版本和发布入口；发布由场景统一完成。

**模块业务规则与验收**

1. 场景是当前唯一发布单元，规则和Skill不独立发布。
2. 场景与规则、场景与Skill均为多对多版本引用；移出场景不删除资产。
3. 场景至少需要一条启用规则或一个启用Skill，不要求两类能力同时配置。
4. 规则负责确定性结构化判断，Skill负责基于审查需求的智能审查，两类能力进入同一场景试跑任务。
5. 场景或任一启用检测资产在试跑后发生变化时，发布必须被阻止并要求重新校验、试跑。
6. 发布后场景、关联规则版本和关联Skill版本不可原地修改。
7. 场景列表运行记录必须合并规则运行记录与Skill运行记录，引用抽屉能够区分来源类型。
8. 规则必须使用已发布图谱，并由图谱带出匹配本体；场景本身不直接选择图谱、本体、主对象和目标类。
9. 当前页面必须覆盖无数据、加载失败、只读资产、引用阻断、并发冲突、生成结果过期、校验失败、试跑失败和依赖快照变化。
